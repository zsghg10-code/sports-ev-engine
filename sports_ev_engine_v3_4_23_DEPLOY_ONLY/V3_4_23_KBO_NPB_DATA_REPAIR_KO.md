# v3.4.23 KBO/NPB 정밀 데이터 보강

- KBO: GameCenter/Naver 라인업에 playerId가 없을 때 KBO 공식 선수검색으로 이름+팀을 재확인해 ID를 복구합니다.
- KBO: 확정 라인업 타자들의 최근 OPS/OBP/근거 경기수를 실제 선수 상세기록에서 집계합니다.
- KBO: 선발 playerId 누락 시 공식 선수검색으로 복구한 뒤 최근 선발 기록을 조회합니다.
- NPB: 일본어 선발명을 NPB 공식 선수 ID/영문명으로 재연결해 최근 선발 및 상대팀 기록 수집 실패를 줄였습니다.
- NPB: 공식 영문 박스스코어의 R(득점)을 최근 팀 득실점으로 집계합니다.
- NPB: 정확한 박스스코어가 2~4경기만 있어도 최근 OPS를 표시하되, 모델 반영 가중치는 표본수에 따라 축소합니다.
- 자료가 실제로 없는 경우 숫자를 임의 생성하지 않고 None/미제공으로 남깁니다.
